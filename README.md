# MCS-Capstone-NRDC-SB-375
Since 2008, SB 375 has relied on Planning Mandates that have failed to curb transportation emissions. Current data shows a widening Implementation Gap: CA is on track for a 29% VMT reduction in its plans, but actual per-capita VMT continues to increase statewide. This Capstone investigates possible solutions, utilizing other states' examples.
